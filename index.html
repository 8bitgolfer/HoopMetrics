Methodology. TS% = PTS / [2 × (FGA + 0.44 × FTA)]. TS+ = 100 × (player TS% / league TS%). 2025–26 league TS% baseline: 58.1%. TS+ is a relative index, not a shooting percentage. The 0.44 factor estimates free-throw possessions. This version derives TS% from rounded per-game source data, so values can differ slightly from precise season-total calculations. Traded players are deduplicated to their combined-season row where provided. Low-sample outliers are included unless filtered. Player data source · League baseline source. Unofficial fan project.
